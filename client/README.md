# 🛒 Jisan Trends — Premium Electronics, Gadgets & Perfume Store

**Jisan Trends** is a modern, responsive, and full-featured e-commerce web application designed for a seamless shopping experience. The platform showcases a curated collection of high-quality electronics, smart gadgets, daily utility appliances, and premium fragrances (such as *Green Bakhor*).

---

## ✨ Key Features

* **📦 Product Catalog & Categories:** Dynamic filtering across Gadgets, Electronics (Fans, Lights, etc.), and Exclusive Perfumes.
* **🔎 Smart Search & Filtering:** Filter products by price, category, and availability.
* **🛍️ Shopping Cart & Checkout:** Real-time cart calculation with smooth checkout integration.
* **📱 Fully Responsive Design:** Optimized for mobile, tablet, and desktop viewports.
* **⚡ Modern UI/UX:** Stylish, contemporary design reflecting the brand's premium identity.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript / React (or Flutter Web)
* **Styling & UI:** Modern Responsive Design Components
* **Database & Backend:** MongoDB / Firebase (Cloud Storage & Data Management)
* **Deployment:** Vercel / Netlify / GitHub Pages
