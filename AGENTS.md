# Project Rules & Instructions

- **Always Deploy to Vercel**: Whenever any feature, page, or bugfix is implemented or updated, always commit and push the changes to `origin main` so that Vercel automatically deploys the latest version to production.
- **Brand & Theme Priority**: Always give first priority to the official **LIORA Beauty & Wear** brand assets (`/liora-logo.svg`), soft blush pink aesthetic, and typography.
